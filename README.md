## Installation
```
npm install bootstrap-preview --save-dev
```

## Usage
In your `package.json`, add the following script:
```
{
  ...
  "scripts": {
    ...
    "preview:bs": "bootstrap-preview src/assets/your-custom-bootstrap.css"
  }
}
```
